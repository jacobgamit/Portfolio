Tableau Sales Dashboard by AdventureWorks Database

“For this project, I used the AdventureWorks dataset to explore how data can be transformed into meaningful business insights. The database contains transactional and master data that can be analyzed to understand sales trends, product performance, customer behavior, and regional performance"

Tools and Programming Language used:

For Data Cleaning and Standardization (SQL Server Management Studio)[SSMS]

For Data Visualization: (Tableau)

The first challenge in this task was figuring out how to set up, store, and create a dynamic hyperlink that will connect the Power BI data to the SQL Server paginated report web portal.

To address these challenges, I created a calculated column for each table and utilize a DAX function namely "SELECTEDVALUE" to capture the user's selected filter.

By placing a dynamic URL hyperlink in the matrix column, users can easily navigate to the desired data in a paginated report.

Now a dynamic URL was created and we are able to view the Data in SSRS Web Portal.
